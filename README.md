# Policy-Tracker 🌍

This Github project serves as a comprehensive policy tracker for countries across the world, including both hemispheres. This includes detailed information on the greater continental USA. The overall policies included concern foreign and domestic agendas for each country. The criteria for this research is thorough and encompasses various policy areas.

## Features

- **Global Coverage**: Track policies from countries in both Northern and Southern hemispheres
- **Comprehensive Policy Types**: Monitor both foreign and domestic policy agendas
- **USA Focus**: Detailed section dedicated to United States policies
- **Policy Categories**: Healthcare, Trade, Defense, Climate, Economy, Social, Environment, and more
- **Interactive Filters**: Filter by hemisphere, continent, country, policy type, and policy area
- **Visual Analytics**: Charts and graphs for policy distribution and trends
- **Detailed View**: In-depth information for each policy

## Installation

1. Clone this repository:
```bash
git clone https://github.com/jmasih1234/Policy-Tracker.git
cd Policy-Tracker
```

2. Install the required dependencies:
```bash
pip install -r requirements.txt
```

## Usage

Run the Streamlit application:
```bash
streamlit run app.py
```

The application will open in your default web browser at `http://localhost:8501`

## Application Structure

- **Overview Tab**: View overall policy statistics and distributions
- **USA Focus Tab**: Dedicated section for United States policy tracking
- **Analytics Tab**: Visualize policy trends and geographic distributions
- **Detailed View Tab**: Access comprehensive policy information

## Policy Data

The application currently includes sample policies from various countries including:
